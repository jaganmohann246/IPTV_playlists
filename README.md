# IPTV Playlists

Public M3U playlist for use with OnePlay and other compatible IPTV players.

## Playlist URL

```text
https://raw.githubusercontent.com/jaganmohann246/IPTV_playlists/main/playlist.m3u8
```

## Import

Copy the playlist URL above and add it as a remote M3U playlist in your IPTV player.

## Contents

This public copy is filtered from the source playlist. It excludes the **Personal-Collection**, **Prime Video**, and **Willow Events** sections to avoid publishing private stream and DRM license information.

Some stream URLs may be temporary or expire, so individual channels may stop working without notice.

## Repository

The source playlist and update workflow are maintained separately in the private [IPTV_channels](https://github.com/jaganmohann246/IPTV_channels) repository.
